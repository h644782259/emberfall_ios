# iOS / iPad 主线整合说明

本分支基于主线提交 `bcf3860155972654b1a5b5c956a0ca4897a5646b`，整合此前玩法升级及第二轮战斗/成长更新。主线在本轮发布前加入的移动端修改已逐项保留：

- iPhone + iPad 通用设备族、横屏全屏、既有安全区布局
- iOS 导出脚本的两种模块安装路径探测、平台工程设置与签名配置原样保留
- `GameFont.Shared`、Noto Sans SC 完整字体、原字体和 Resources 目录的资产 GUID 与许可
- 触屏操作指南、移动端暂停菜单入口、UI 与掉落物的共享字体生命周期
- `ProjectSettings/ProjectVersion.txt` 指定的 Unity 6000.6.4f1

## 三处源码整合

主线的旧浮字类在玩法分支中已经拆为 `Combat/FloatingNumber.cs`，因此把字体修正应用到新的描边/暴击浮字实现，而不重复恢复旧类。世界标牌保留稳定英文对象ID和中文显示内容，优先使用主线完整共享字体，18字形的已验证子集作为固定标签后备。README 同时保留 iPad 安装指引，并更新已经整合的新玩法说明。

完整 Noto 字体二进制没有修改，直接继承上述主线树中的 blob `fc0fda9394367c16c1af7555a2ae4d5e2e6a6f02`。本云工作区没有重新下载该大型字库，发布树通过 Git SHA 保留原资源；固定标签后备子集的实际二进制字形已检查。不能把这一点当成完整字体的 Unity 导入/渲染验证。

## 验证范围与版本差异

工程要求 Unity 6000.6.4f1；云端已有并用于编译检查的是 Unity 6000.6.3f1。结果仅证明代码通过这套已安装程序集的兼容编译，不代表精确匹配目标编辑器补丁版本，也不代表完成 Unity 导入、Play Mode 或 iPad 真机测试。

另运行11组纯生产逻辑测试、字体后备资源检查、合并完整性检查，保留最终源文件哈希。未启动 Unity，没有安装或降级项目编辑器，没有生成/签名 Xcode、IPA，也没有变更任何远程账号或签名授权。

发布前请在 Unity 6000.6.4f1 + iOS Build Support 上导入并导出新目录，测试 iPhone 和至少一种4:3 iPad：中文UI/场景/浮字/掉落字、触屏指南、双指移动攻击、选点取消、所有新营地选项、前后台恢复、Boss预警与伙伴受击，以及旧存档迁移。
