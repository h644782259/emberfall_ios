游侠多杀保存风险：同一次动作内击杀奖励仍即时更新，持久化在动作结束时合并；动作外维持即时保存。结算队列即使某回调抛错也继续执行其余回调，并重新抛出首个原异常。真实保存回归覆盖多杀、保存失败／重试、结算回调异常和重复击杀。这是对同步写盘风险的修复，未实机复现数秒卡死，不能据此认定根因。
